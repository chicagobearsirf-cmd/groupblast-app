# GroupBlast Customer Downloads

This repository is the official binary-only release channel for GroupBlast.

- Customer installers and updater metadata are published under
  [Releases](https://github.com/chicagobearsirf-cmd/groupblast-app/releases).
- GroupBlast application source code is proprietary and maintained in a
  separate private repository.
- This repository must never contain application source, internal handoffs,
  customer data, credentials, browser profiles, or development artifacts.

Windows installers may display **Unknown Publisher** until GroupBlast has a
Windows code-signing certificate. macOS releases are Developer ID signed,
notarized, and stapled before publication.

For product information and downloads, visit
[group-blast.world](https://group-blast.world).
